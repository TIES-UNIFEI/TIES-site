# Identidade visual do TIES

Os arquivos SVG desta pasta foram preparados a partir das versões transparentes enviadas.

- `logo-ties-unifei.svg`: versão compacta TIES/UNIFEI. Já aplicada no cabeçalho das páginas PT, EN e ES.
- `logo-ties-unifei-grupo.svg`: versão com a identificação de grupo de pesquisa e laboratório.
- `logo-ties-maior.svg`: versão horizontal com a palavra TIES em maior destaque.
- `logo-ties-menor.svg`: versão horizontal com a palavra TIES em menor destaque.
- `logo-ties-simbolo.svg`: símbolo isolado, útil para ícone do site e aplicações pequenas.

Os arquivos são vetoriais e têm fundo transparente. A área de visualização foi ajustada para remover margens transparentes excessivas, sem rasterizar o desenho.

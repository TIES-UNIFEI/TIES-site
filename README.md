# TIES — UNIFEI | Site institucional inicial

Estrutura inicial trilíngue (português, inglês e espanhol) para GitHub Pages.

## Estrutura
- `index.html`: direciona para português (`pt/`)
- `pt/index.html`: português
- `en/index.html`: inglês
- `es/index.html`: espanhol
- `assets/css/style.css`: estilos compartilhados
- `assets/js/main.js`: menu responsivo
- `CNAME`: domínio personalizado

## Como testar
Abra `index.html` no navegador ou use a extensão Live Server no VS Code.

## Como publicar
Envie todos os arquivos e pastas para a raiz do repositório `TIES-UNIFEI/TIES-site`, preservando a estrutura.
O GitHub Pages deve publicar a partir da branch `main`, pasta `/ (root)`.

## Antes da publicação definitiva
1. Substituir o logotipo provisório tipográfico pelo arquivo oficial do TIES.
2. Validar os textos institucionais com a equipe.
3. Inserir e-mail, endereço, redes e contatos oficiais.
4. Adicionar imagens autorizadas do laboratório e da infraestrutura.
5. Confirmar com a TI da UNIFEI o registro DNS CNAME `ties` apontando para `ties-unifei.github.io`.
6. Confirmar a configuração do domínio personalizado em Settings > Pages e HTTPS.

Os textos e áreas de atuação apresentados são uma primeira proposta editorial, não uma descrição institucional final.
